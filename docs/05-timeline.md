# 研究阶段（摘要）

> 面向公开阅读的阶段划分；内部逐轮记录（含完整证据、命令与输出）不随仓库发布。

## 阶段 1 · 样本与基线

- 登记样本身份（哈希、体积、dex 数量、ABI 集合）
- 确立「只读样本、工作副本」纪律：先记基线，再做任何解析
- 产出：样本清单与哈希台账

## 阶段 2 · 加固结构识别

- 读 manifest 判定是否存在第三方壳
- 识别 DEX 加密方案三要素：加密载荷、指令表变换、尾部载荷容器
- 恢复业务 DEX 并做结构断言（类数 / 方法数 / 指令字节数一致）
- 产出：加固结构分析与恢复审计

## 阶段 3 · 原生层清单化

- 全量解包 `.so`，按 ABI 归组，逐文件记录哈希
- 每个库在 IDA 中建库（headless），得到函数级索引
- 产出：原生库清单 + 数据库矩阵

## 阶段 4 · 检测分诊

- 按 10 类字符串指标 + 22 项敏感导入定位候选
- 候选回溯引用函数，再逐函数反编译判读
- 每条命中给出**误报归因**；每个「无命中」给出覆盖边界
- 产出：分诊报告 + 判定表

## 阶段 5 · 检测代码确认

- 灰区函数全部 Hex-Rays 导出
- 确认判定基元（文件存在性、逐行关键字匹配等）
- 反向确认调用链：Java 入口 → native 汇总函数 → 各检测子函数
- 产出：检测代码档案

## 阶段 6 · 上报链路还原

- Java 侧：采集字段、触发条件、开关来源、隐私门槛
- native 侧：材料组装、长度派生、时间差
- 传输侧：接口类型、字段语义、重试策略
- 处置侧：失败路径与延时退出机制
- 产出：链路结构图与逐段证据

## 阶段 7 · 评审、抽查与脱敏

- 抽样复核：判定基元、调用链、触发条件
- 交叉核对：不同证据源是否互相矛盾
- 脱敏发布：剥离密钥 / 参数 / 偏移 / 工具 / 样本 / 主体标识，保留结构与结论

## 尚未闭合（正文以 `unknown` 标注）

- 硬件证明（attestation）判定逐行
- 加密材料的单项折算算法
- 另一 ABI 的完整分诊
- 「无检测」结论的穷举式复核
